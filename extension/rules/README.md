# Bundled network rules

Harbor Guard 0.3.3 includes **51,948 advertising domains** and **46,719 tracking
domains**, compiled into **855 ad rules** and **845 tracker rules**, including
compatibility exceptions. These are a hostname subset of the bundled EasyList
and EasyPrivacy snapshots dated 24 October 2026, combined with local entries.

`source-manifest.json` records source URLs, upstream versions, exact SHA-256
hashes, license details and conversion counts. `hosts.json` holds the original
local host entries. `ads.json`, `trackers.json`, `catalog.js` and `LICENSE` are
generated by `scripts/update-rules.mjs` from the original source snapshots.

See `ATTRIBUTION.md` and the adjacent `LICENSE` for the EasyList authors'
attribution and CC BY-SA 3.0 terms. Raw snapshots, license and conversion source
are supplied in the accompanying source archive.

## Coverage

Rules block third-party subresource requests to selected domains and their
subdomains. They do not block top-level navigation or all first-party tracking.
The converter selects pure hostname rules, with an optional third-party flag.
It does not implement EasyList's full path, regex, resource-specific, cosmetic,
scriptlet or redirect syntax. Domain entries are grouped in batches of at most
500, keeping the result below Chrome's guaranteed static rule quota.

Scoped exceptions become higher-priority URL allowances limited to their
initiating sites. Document-wide or unsupported scoped exceptions use broader
site exemptions. Unscoped host exceptions remove overlapping block domains.
Unsupported global network exceptions stop the import. Upstream exceptions
also apply to local entries and across both categories.

There are no blanket blocks for YouTube or its video/CDN domains. The separate
YouTube helper handles supported player ad metadata and visible ad controls.
Server-inserted ads and unlisted hosts can still pass through. Domain/rule counts
describe configured coverage, not blocked requests or a live ad-test score.

## Rebuild or refresh

Run from the project root with Node.js 20 or newer:

```powershell
node scripts/update-rules.mjs
node scripts/update-rules.mjs --check
node scripts/update-rules.mjs --download
```

The first two commands stay offline. `--download` fetches official EasyList,
EasyPrivacy and CC BY-SA license text. The extension itself makes no filter
downloads and executes no remote code. Sources live at:

```text
data/filter-sources/easylist.txt
data/filter-sources/easyprivacy.txt
data/filter-sources/LICENSE
```

Preserve the original bytes for reproducible hashes. The updater validates
format, minimum list size and license stability before staging outputs. An
existing maintained build cannot silently fall back to starter coverage if its
snapshots are missing. Do not remove exceptions to force an import to succeed.
Write/rename failures attempt rollback and report preserved recovery files if
restoration fails.

After updating filters, reload the extension and affected sites. Check normal
playback, sign-in and checkout. A site exception pauses all layers on that domain
and its subdomains; reload the site after changing it. No network-request URL log
is collected. Activity records only aggregate cleanup actions and timestamps.
